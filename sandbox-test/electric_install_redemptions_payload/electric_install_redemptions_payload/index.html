    contractor_company_name

    The name of the primary contracting company for the project.

    • is required

    Minimum Length: 1 Maximum Length: 64

    contractor_name

    The name of the primary contractor for the project.

    • is required
    • Type: string

    Minimum Length: 1 Maximum Length: 64

    equipment_and_material_cost

    This should not include the cost of the qualifying product(s) for this rebate. Those should be provided using the /electric/reservations/{reservation_id}/product-redemptions endpoint. Include incidental equipment and materials costs directly related to installation here.

    • is required
    • Type: number

    Must be multiple of: 0.01 Minimum Number: 0

    installation_cost

    The installation costs associated with this redemption. To qualify, the installation must be performed by an approved contractor. Also see is_contractor_eligible. A zero dollar installation cost is only allowed when is_final_project_redemption is true.

    • is required
    • Type: number

    Must be multiple of: 0.01 Minimum Number: 0

    is_contractor_eligible

    The contractor is eligible if they are on the state's approved list.

    • is required
    • Type: boolean

    Constant: True

    is_final_project_redemption

    Set this to true if the project work has been completed and there will be no more redemptions made on this reservation. This will, among other things, free up any remaining reservation amount for the household's future use.

    • is required
    • Type: boolean

    post_retrofit_inspection_passed

    State attests that if a post-retrofit inspection was conducted and failed that the issues were remedied before the rebate was provided to the claimant. Note: this field is currently optional but will be required in a future release.

    • is required
    • Type: enum
    Value
    NA
    NO
    YES

    This is a calendar date in the form YYYY-MM-DD. Time zone is immaterial.

    • is conditionally required
    • Type: string

    Minimum Length: 10 Maximum Length: 10 Regex Pattern: ^\d{4}-\d{2}-\d{2}$

    rebate_deducted

    • is required
    • Type: number

    Must be multiple of: 0.01 Minimum Number: 0
